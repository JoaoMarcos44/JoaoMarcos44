## About me

I'm a Computer Science student at **IFCE, Brazil**. I build backend services, web interfaces, and tools for working with AI agents.

My work spans **Java and Spring Boot**, **TypeScript and Node.js**, and **Python**. I also explore machine learning and computer vision, especially their applications in medical imaging.

I enjoy tracing bugs back to their causes, understanding unfamiliar codebases, and building tools that make development easier.
